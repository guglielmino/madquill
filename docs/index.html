How it works

A native Quick Look extension for macOS.

  1. 1

    Install the app

    Download the signed DMG and drag MadQuill into Applications.

  2. 2

    Launch once

    The first launch registers the Quick Look extension and ensures macOS recognizes Markdown previews.

  3. 3

    Preview in Finder

    Select any Markdown file and use Quick Look for a clean rendered view.

Installation

Easy for first-time users.

Every release is packaged as a macOS DMG with a simple install flow: download, open the disk image, drag the app into Applications, and launch it once to register the extension.

Quick steps

  1. Download the DMG from GitHub Releases.
  2. Open the DMG and drag MadQuill.app to Applications.
  3. Open the app once to finish registration.
  4. Use Quick Look on any Markdown file in Finder.
